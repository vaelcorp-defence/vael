# Security Policy

## Supported Versions

Currently, only the latest release is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.5   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a vulnerability in Vaelcorp Defence itself, please do not open a public issue. 

Instead, please send an email to **vaelcorpdefence@gmail.com**. We will respond within 48 hours. Please include:
- A description of the vulnerability.
- Steps to reproduce it.
- Any potential impact.

Thank you for helping keep Vaelcorp secure!
